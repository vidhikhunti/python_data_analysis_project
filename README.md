# E-commerce Data Analysis using Python

## Project Overview
This project analyzes ecommerce sales data using Python for data cleaning, analysis, and visualization. The project focuses on generating business insights from sales, profit, discount, and category performance data.

## Tools & Libraries Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis & Visualizations
- Category-wise sales and profit analysis
- Profit margin analysis
- Discount vs profit analysis
- Correlation heatmap
- Cumulative sales analysis
- Loss-making sub-category analysis
- Bar charts, pie charts, histograms, and line charts
